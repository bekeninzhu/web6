THE LAST SLICE — Assignment 6

Іске қосу: ZIP-ті толық шығарып, index.html файлын Chrome/Edge-та ашыңыз.
Интернет те, npm install да, сервер де қажет емес.

Файлдар: index.html — құрылым; style.css — дизайн; script.js — барлық jQuery
әрекеттері; jquery.min.js — жергілікті кітапхана; avatars/ — Open Peeps
аватарлары (DiceBear, CC0). Торт суреті index.html ішіндегі SVG арқылы жасалған.

20 шарт оң жақтағы The case files панелінде орналасқан. Панельді төмен
айналдырсаңыз, қалған шарттар көрінеді. Телефонда шарттар ашылмалы тізімде.
Нәтиже Investigation log-та шығады, бет негізгі алаңға өзі жылжиды.

Қонақты басу — мәлімет ашу. Esc, × немесе терезе сырты — жабу.
Басқа қонақты басу — оның мәліметіне ауысу.
Move — қонақты басқа бөлмеге ұшырып көшіреді, массивті жаңартады.
Sort by time / Picture order — уақытпен сұрыптау / бастапқы ретті қайтару.
Clear spotlight — барлық қонақты жарық көрсетеді. Reset party — бәрін қайтарады.

Кодтағы негізгі бөліктер:
g() және rooms — деректер; guestCard() және renderHouse() — бет құрастыру;
queries — 20 DOM іздеуі; finishLayout() — анимацияларды реттеу;
openModal()/closeModal() — мәлімет терезесі; fly() — қозғалыс көшірмесі.

Барлық анимация jQuery арқылы жасалады. CSS transitions/animations жоқ.
Қосымша интерфейс кітапханалары мен құрастыру құралдары қолданылмаған.
